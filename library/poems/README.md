# Rote import files

Format: line 1 = title, line 2 = author, blank line, then the poem. Blank lines inside the poem are stanza breaks. Leading spaces are intentional indentation.

All poems here are public domain in the US. Texts were typed from standard editions; before learning one, compare it once against the Poetry Foundation / Gutenberg link in ../POEMS.md. Open a single file with `open -a Rote <file>.txt` or build one archive with `python3 tools/txt2rote.py library/poems library/rote-import.json` and fix any stray punctuation in Rote's editor.
